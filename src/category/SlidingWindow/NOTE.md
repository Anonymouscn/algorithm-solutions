# Sliding Window - 滑动窗口

## 什么是滑动窗口
> 滑动窗口是一种处理 **数组 / 字符串** 中连续区间问题的常用技巧：用两个指针维护一个窗口 [𝑙,𝑟]，右指针不断右移把新元素纳入窗口并更新统计；当窗口不满足约束（或需要优化答案）时，左指针右移移出旧元素并同步更新统计。由于两个指针都只向右移动，元素通常最多被加入和移出各一次，因此很多问题可从 $𝑂(𝑛^2)$ 优化到均摊 $𝑂(𝑛)$（前提是窗口内统计的维护可做到 $𝑂(1)$ 均摊）。

## 应用场景
1. 固定长度窗口（窗口大小 k 固定）
    
    适用：需要对每个长度为 k 的连续区间做统计
    * 长度为 k 的子数组  最大/最小 和 、平均值
    * 每个窗口内满足条件的数量（例如：窗口内某元素出现次数）
    * 固定窗口的 distinct 元素个数（配合哈希计数）
    * 固定窗口 最大值/最小值（常配合单调队列，把每次查询降到均摊 $O(1)$）

2. 最长/最短 子串/子数组（满足约束的最长连续区间）

    适用：窗口“越大越好”，但必须满足条件；不满足就收缩左端
    * 最长子数组使得窗口内某条件成立 \
        如：
        * 最长无重复字符子串
        * 最长包含至多 K 种不同字符/数字的子串（at most K distinct）
        * 和 ≥ S 的最短子数组
        * 覆盖目标字符集的最短子串
        * 满足“至少包含 K 个某元素”的最短区间

3. “至多 / 恰好 K” 计数类问题

    适用：问满足某条件的子数组/子串数量
    * “至多 K 个不同元素”的子数组数量
    * “至多 K 个 1 / 0 / 奇数”的子数组数量
    > 恰好 K 通常用：count(≤K) - count(≤K-1)

5. 子数组和/频率统计的在线维护（窗口内状态可增可减）

    适用：窗口内信息能在元素进出时 $O(1)$ 更新
    * 窗口内字母频次、数字频次、某模式出现次数
    * 窗口内当前和、当前乘积（乘积常见于“乘积 < K 的子数组个数”，注意 K=0/1 边界）
    * 窗口内某种“违规点”数量（比如：不满足条件的元素个数 ≤ K）

6. 与数据结构结合的滑动窗口优化

    适用：窗口内需要更复杂的“查询/维护”
    * 单调队列：窗口 最大 / 最小 、max-min 约束、滑动最值 DP
    * 堆 / 平衡树：窗口中位数、Top-K（通常 $O(nlogn)$）
    * 哈希计数：窗口 distinct 数、重复检测、字符覆盖

7. 字符串模式相关（窗口覆盖与匹配）

    适用：需要判断窗口是否“覆盖”某个需求
    * 最小覆盖子串（覆盖所有目标字符及其次数）
    * 找所有字母异位词（Anagrams）：固定窗口 + 频次数组比较/差分计数
    * “包含某些模式”的连续区间检测（窗口计数满足条件）

8. 二维/流式处理的“滑动窗口”

    适用：数据是流式到达，或在二维上做局部统计
    * 流式数据的最近 k 个元素统计（rolling average / rolling max）
    * 图像 / 矩阵 的滑动窗口求和（常用前缀和更快，但窗口思想一致）
    * 时间序列的移动平均、移动方差（工程常见）
